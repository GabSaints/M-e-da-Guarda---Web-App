# Entregável web app — Mãe da Guarda

Protótipo do produto digital para responsáveis. Abra `index.html` em navegador moderno. HTML, CSS e JavaScript são editáveis e funcionam sem banco de dados ou serviços externos. Links das fontes exigem internet.

Entrega: roteiro em 3 passos, 4 caminhos contextuais, orientação imediata quando há relato de agressão/ameaça, frases copiáveis, modelo de contato com a escola e resumo imprimível. A escolha fica apenas na memória da página; não há cadastro, campo livre, analytics ou armazenamento de relatos.

Este ZIP é um **pacote de implantação para o aluno**, não um mecanismo de acesso pago. Se for hospedado em endereço público, o conteúdo ficará público. Antes de vender, configurar acesso protegido ligado a pagamento verificado, suporte, termos, privacidade, reembolso e revisão editorial/profissional. Leia `STATUS.md`.

Servidor local: `python3 -m http.server 4177` dentro desta pasta. Abrir `http://localhost:4177/`.
